📋 투민시스템 홈페이지 인수인계 및 운영 매뉴얼

이 문서는 투민시스템 홈페이지(twominsystem.com)의 새로운 관리자가 홈페이지의 주요 내용을 수정하고, 최신 정보를 업데이트 및 관리할 수 있도록 정리한 인수인계용 실무 매뉴얼입니다.

개발 지식이 없는 비개발자 관리자도 순서대로 따라 하면 모든 작업을 안전하게 처리할 수 있도록 작성되었습니다.

📂 1. 홈페이지 기본 정보 및 작동 원리

투민시스템 홈페이지는 별도의 데이터베이스(DB) 서버나 복잡한 백엔드 없이 작동하는 정적 웹사이트(Static Website)입니다.

  • 홈페이지 주소 (도메인): twominsystem.com
  • 서버 호스팅 서비스: GitHub Pages (깃허브 페이지)
    • 비용이 완전히 무료이며, 대량의 트래픽(접속자 수)이 몰려도 서버가 다운되지 않는 아주 안정적인 호스팅 서비스입니다.
  • 로컬 작업 폴더 경로: I:\홈페이지\twoomin (모든 이미지, 매뉴얼 PDF 및 HTML 소스 파일이 들어 있습니다.)
  • GitHub 원격 저장소: hammertechkorea/twoomin-static

💻 2. 최초 1회 업무 준비 사항 (새 컴퓨터에서 처음 작업할 때만)

새로운 컴퓨터에서 홈페이지를 처음으로 관리하게 되었다면, 아래 두 프로그램을 먼저 설치해야 합니다.

  1. Git 설치: https://git-scm.com/download/win에서 윈도우용 Git을 다운로드하여 기본 옵션으로 설치합니다.
  2. VS Code(코드 편집기) 설치: https://code.visualstudio.com/에서 VS Code를 다운로드하여 설치합니다. (메모장보다 오타를 찾기 훨씬 쉽습니다.)
  3. GitHub CLI 로그인 인증:
    • 키보드의 Windows 키를 누른 뒤 cmd를 입력하여 명령 프롬프트를 실행합니다.
    • gh auth login 명령어를 입력하고 엔터를 칩니다.
    • 화면의 질문에 다음과 같이 답합니다:
      • What account? ➡️ GitHub.com 선택
      • Preferred protocol? ➡️ HTTPS 선택
      • Authenticate Git? ➡️ Yes 선택
      • How to authenticate? ➡️ Login with a web browser 선택
    • 브라우저 창이 열리며 8자리 일회용 코드를 입력하라는 창이 뜹니다. 명령 프롬프트 창에 표시된 8자리 코드를 그대로 입력하고 GitHub 계정으로 로그인 및 승인(Authorize)을 마치면 연동이 완료됩니다.

✍️ 3. 주요 홈페이지 수정 및 관리 작업 안내

모든 작업은 VS Code에서 I:\홈페이지\twoomin 폴더를 열고 진행해야 합니다.
(VS Code 실행 ➡️ File ➡️ Open Folder ➡️ I:\홈페이지\twoomin 선택)

① 메인 화면(소개글, 전화번호, 주소 등) 수정하기

  • 대상 파일: index.html
  • 작업 방법:
    1. index.html 파일을 엽니다.
    2. 수정하고 싶은 글자(예: 사무실 주소 또는 전화번호)를 Ctrl + F로 검색하여 찾아냅니다.
    3. 텍스트를 원하는 대로 수정한 뒤 Ctrl + S를 눌러 저장합니다.

② 상세페이지 제품 정보 및 스펙 수정하기

상세페이지의 제품 스펙이나 상세 이미지를 교체하려면 자바스크립트로 구현된 제품 데이터베이스를 수정해야 합니다.

  • 대상 파일: product-detail.html
  • 작업 방법:
    1. product-detail.html 파일의 하단부(약 580번 라인 이후)에 있는 const productDb = { ... } 코드를 찾습니다.
    2. 원하는 모델명(예: TA300)을 찾아 아래 설명에 따라 수정합니다.
    'TA300': {
        name: 'TA300 RGB',                // 제품 이름
        category: '케이스',                // 분류
        badge: 'FLAGSHIP PREMIUM',        // 제품 우측 상단 뱃지 문구
        subtext: '경계를 허물다. 무결점 프레임리스...', // 상세페이지 서브 설명글
        colors: ['black', 'white'],       // 제공 색상 (색상 전환 버튼 생성 기준)
        img: {
            'black': 'TA300_RGB_Black_1000x1000.jpg', // 블랙 썸네일 이미지 파일명
            'white': 'TA300_RGB_White_1000x1000.jpg'  // 화이트 썸네일 이미지 파일명
        },
        detailImgs: {
            'black': 'TA300_RGB_Black_20260120.jpg', // 블랙 상세 인포그래픽 이미지
            'white': 'TA300_RGB_White_20260120.jpg'  // 화이트 상세 인포그래픽 이미지
        },
        quickSpecs: [
            { label: '규격', val: 'ATX 미들타워 (파노라마 뷰)' }, // 요약 스펙 목록
            ...
        ],
        specs: {
            '제품 분류': 'PC 케이스 (ATX 미들타워)',               // 스펙 상세 표 항목들
            '메인보드 지원': 'Standard ATX, Micro-ATX, Mini-ITX',
            ...
        }
    },
⚠️ 자바스크립트 문법 주의 사항 (위반 시 사이트 하얗게 변함)
  1. 쉼표 (,) 누락 주의: 각 속성의 끝에는 반드시 쉼표( , )가 붙어 있어야 합니다.
  2. 따옴표 쌍 맞추기: 글자를 감싸는 따옴표(' 또는 ")는 앞뒤에 무조건 한 쌍으로 닫혀야 합니다.
  3. 괄호 짝 맞추기: { } 중괄호와 [ ] 대괄호는 열린 만큼 반드시 닫혀야 합니다.

③ 고객지원(SUPPORT) 자료실 매뉴얼 및 안내글 관리하기

  • 대상 파일: support.html
  • 작업 방법:
    • 다운로드 가능한 매뉴얼 PDF 등록:
      1. 용량을 최적화한 PDF 파일을 twoomin 루트 폴더 내에 저장합니다.
      2. support.html 파일 약 360번 라인 근처의 const downloadDb = [ 아래에 기존 항목을 복사하여 아래 형식으로 새 매뉴얼 정보를 추가합니다.
          {
        model: 'TA300',                           // 검색할 모델명
        name: 'TA300 RGB',                        // 제품 노출 이름
        category: 'case',                         // 카테고리 (case 또는 cooler)
        categoryKo: 'PC 케이스',                   // 화면에 표시될 한글 분류
        title: 'TA300 RGB 조립 설명서 (사용자 매뉴얼)', // 다운로드 제목
        fileName: 'TA300_RGB_Manual_KO.pdf',       // 표시될 파일명
        fileSize: '4.5 MB',                       // 파일 크기
        fileType: 'PDF',                          // 파일 형식
        date: '2026-01-20',                       // 등록 날짜
        link: 'TA300_RGB_Manual_KO.pdf'           // 실제 다운로드될 파일명 (일치해야 함)

      1. 별도의 매뉴얼이 제공되지 않는 단순 보급형 케이스인 경우, support.html 약 450번 라인 근처의 const standardModels = { 안에 다음과 같이 등록합니다.
          'TM40': {
        name: 'TM40',
        type: '실속형 컴팩트 가성비 케이스',
        desc: '본 제품은 표준 구조 케이스로, 별도의 매뉴얼이 제공되지 않는 직관적인 제품입니다...'

      이 리스트에 등록된 모델을 사용자가 검색하면 매뉴얼 파일 대신 작성한 설명글이 담긴 파란색 안내 카드가 화면에 자동 출력됩니다.

🖼️ 4. 이미지 및 매뉴얼 파일 규격 규칙 (매우 중요)

대용량 이미지는 로딩 속도를 매우 지연시켜 고객 이탈을 유발합니다.

  • 포맷 규격: 상세 이미지나 인포그래픽은 가급적 .jpg 포맷으로 통일해 주세요.
  • 용량 최적화: 10MB가 넘는 원본 이미지는 반드시 무료 온라인 압축 사이트(예: iloveimg.com)에서 용량을 3MB 이하 (가급적 1MB 대)로 줄여서 사용해야 모바일에서도 빠르게 열립니다.
  • 저장 위치: 모든 추가 이미지와 PDF 파일은 twoomin 폴더의 루트(가장 바깥쪽) 경로에 직접 넣어 두어야 다른 파일들이 인식할 수 있습니다.

🚀 5. 수정한 홈페이지 인터넷에 반영(배포)하기

수정이 모두 완료되었다면 윈도우 환경에서 제공되는 자동화 도구를 실행하면 됩니다.

  1. 모든 파일을 저장(Ctrl + S)했는지 확인합니다.
  2. I:\홈페이지\twoomin 폴더 내부의 publish.bat 파일을 더블클릭하여 실행합니다.
  3. 검은 도스 창이 열리며 자동으로 서버의 파일들을 정렬합니다.
  4. "수정 내용을 간단히 입력하세요 [기본값: 수정함]: " 메시지가 나타나면 무엇을 수정했는지 간단히 적고(예: TA400 이미지 추가) Enter를 누릅니다.
  5. 자동으로 GitHub 서버에 업로드되며 약 1~2분 뒤 인터넷에 반영됩니다.
  6. 확인 시 반드시 인터넷 브라우저에서 Ctrl + Shift + R (강력 새로고침)을 눌러 이전 쿠키 정보를 날리고 확인하셔야 바로 수정된 내용이 보입니다.

🔍 6. 자주 묻는 오류 및 해결법

Q1. 수정을 완료했는데 홈페이지 화면이 완전히 백지로 나옵니다.

  • 원인: product-detail.html 또는 support.html 파일의 자바스크립트(productDb 등) 데이터 수정 중 쉼표( , )를 빠뜨렸거나 괄호 짝을 위반하여 발생한 문법 오류입니다.
  • 해결법:
    1. 크롬 또는 엣지 브라우저에서 홈페이지를 엽니다.
    2. 키보드의 F12 버튼을 누릅니다.
    3. 상단 메뉴 중 Console (콘솔) 탭을 누릅니다.
    4. 빨간색 글씨로 에러가 발생한 줄 번호(예: product-detail.html:629)가 표시됩니다.
    5. VS Code로 돌아가 해당 줄 번호 근처의 문법 위반 요소(주로 쉼표 누락)를 고쳐주면 즉시 정상 복구됩니다.

Q2. publish.bat 실행 시 에러 메시지가 뜨며 배포가 실패합니다.

  • 원인: 깃허브 토큰 만료 또는 로그인 만료로 인한 권한 오류입니다.
  • 해결법: 이 문서 2. 최초 1회 업무 준비 사항의 3) GitHub CLI 로그인 인증 방법을 다시 한번 진행하여 로그인을 갱신해 주시면 해결됩니다.
